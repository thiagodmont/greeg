## Quality (SCIP oracle)

Ground truth: SCIP occurrences from `rust-analyzer scip`, `scip-python`, `scip-typescript`. Names are sampled from symbols defined in the repository, stratified by ambiguity (number of definitions with that name) and kind. Acc@k: a true definition is among the first k locations the tool prints for the bare name (`greeg def NAME`, `rg -nw NAME`, `grep -rnw NAME`). Reference recall: SCIP reference occurrences found by `greeg refs NAME --budget 0`. Classification: `greeg -w NAME --json` hit kinds vs SCIP roles on the same line, from stored spans and with `--precise`. Context@500: the first 500 lines of each tool's output for the bare name; useful = lines that carry a SCIP occurrence of the name; tokens are o200k_base counts.
